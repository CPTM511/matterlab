# F1: one saved native-force conservation audit

This is a new practical monitored resource protocol. It neither passes nor weakens the closed association protocol. Stage start/deadline are immutable in stage-private.json: 600 seconds all roles, including preparation, independent pre-execution review, one saved-data invocation, post-result review and checkpoint. Analysis process allowance is 60 seconds including launch through observed return, with at least 90 seconds remaining before admission. Ordinary scheduling and finite I/O are explicit assumptions; blocked setup/cleanup/terminal I/O may defeat monitoring. Observed overruns are failures, not certified containment. Never renew a clock. No model/torch/numpy import, forward, AD, DFT, network service, environment creation, installation or scientific anchor.

Question: does the previously saved reference's native force tensor already violate the joint translation-gradient/final-rounding premise before N1's added derivative queries? This is distinct from the consumed two Hessian rows/six axis sums. It cannot diagnose the cause of those residuals or historical replay drift.

Inputs: exact G1 reference-base and N1 NPZ files, member f_0.npy and 240 payload bytes pinned in inputs.json. Shape20x3, little-endian binary32,C-order; both whole archives must match and payloads must be identical. N1 prediction_hook saves native model outputs before exact_baseline and query_rows; independently saved G1 baseline predates added N1 queries. Published native_worker/native_capture and model/encoder/converter source hashes are pinned. Full source/reference inference is conditional, not a backend or differentiability certificate. Original project license and third-party boundaries remain unchanged; no public export in this stage.

Independent review must PASS the exact manifest and synthetic checks before one real invocation. Fresh usage under900seconds, clean pinned public checkout, current remote head and public empty active_work, fresh visible-process/ownership observation are required. A private exclusive saved-data invocation marker is consumed before the analysis child; no retry on exception, partial result, timeout or mismatch. It is not a model attempt token. No sums may be inspected before freeze/review. Preparation fixtures use synthetic values only, labelled accordingly.

Parser: NPZ six exact expected members, no duplicates/encryption, bounded uncompressed member sizes, archive and member hashes; accept NPY1.0 with bounded ASCII literal header, exact keys/representation and exact payload length. Unsupported formats, nonfinite binary32 and maximum finite magnitude endpoints STOP, with no approximation. No pickle or floating conversion. All calculations use integer words and Fraction.

For positive nonzero finite words, exact adjacent representable values define midpoint endpoints. Include both ties conservatively irrespective of parity. Negative cells reflect positive cells. Both signed zeros use the common symmetric closed interval [-2^-150,2^-150], a conservative superset. Subnormals and normal powers of two use their actual unequal adjacent spacings. Maximum finite words are unsupported and rejected before summation. This avoids inventing an infinity midpoint.

Exactly60 components, three Cartesian-axis sums of20 cells. Every raw word, component cell and axis endpoint is retained as integer numerator/denominator, with axis/atom identification. Units eV/Angstrom. Exclude zero iff lower>0 or upper<0, no epsilon. Distance d is lower if positive, -upper if negative, otherwise0. When excluded, d/20 is a conditional lower bound on at least one true force component's distance from its reported rounding cell, assuming an exact zero-sum force vector. It is not a bound on every component, not an upper bound, and not necessarily distance from the reported float value. Non-exclusion is inconclusive.

Output schema1: components60,axis_sums3,units,cells[{atom,axis,bits_hex,lower,upper}],sums[{axis,lower_eV_A,upper_eV_A,zero_excluded,distance_to_zero_eV_A,conditional_some_component_distance_from_cell_lower_bound_eV_A,interpretation}],input_identities,elapsed timing. Preserve original process stdout/stderr, counter marker and terminal receipt even if rejected. Exact rational endpoints are authoritative; no decimal approximation required.

Original replay energy1e-5eV/force1e-6eV/Angstrom/stress1e-7eV/Angstrom^3 at rtol0 remain failed/unchanged. The0.005eV/Angstrom^2 derivative threshold is unrelated and unchanged. No conservation result substitutes for these comparisons. Exclusion rejects only the joint exact-gradient/final-rounding premise and conditionally locates a first-gradient incompatibility before added queries; it does not identify AD error, historical cause, accuracy, migration, stability or application performance. Zero inclusion supports no causal conclusion.

After terminal analysis, independent saved-result review verifies all60 recorded cells/three sums against exact implementation/input hashes and interpretation within the same total deadline. Verification of the saved output is not another analysis invocation; no re-entry to launcher. Stop/checkpoint if any precondition, integrity, arithmetic/representation, chronology, ownership, freshness or timing gate fails. No variant, expanded input or publication.
