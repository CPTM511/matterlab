## Question and value of the observation

Does one fresh process under the saved C1 default-dispatch condition reproduce all six saved model tensors and all ASE observables exactly, with the entire recorded same-condition runtime/build description, raw input, consumed neighbors, graph and model parameters unchanged?

The published C0 already exactly reproduced R1. The altered C1 produced finite different derivatives at identical captured inputs, graph and weights, but failed its frozen combined gate because the build string repeated the intended capability change. No altered-condition repeat was run. One fresh altered-condition evaluation is the cheapest direct observation of that remaining pairwise repeatability question. A new control, alternative backend, displacement sweep or candidate campaign is outside this protocol.

H1: every entry, capture, invariant and process/resource gate passes and P1 reproduces C1 exactly. This establishes equality for this pair under the recorded condition, not a statistical distribution. H2: those gates pass but an output differs, showing that the recorded fingerprint and specified capture implementation do not ensure exact repeatability. A failed assumption, incomplete capture or unsuccessful process makes the result inconclusive. The newly added assertion instrumentation is a possible unisolated influence if outputs differ; H2 cannot attribute a difference uniquely to numerical dispatch or intrinsic nondeterminism.
