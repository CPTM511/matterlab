# Model and generated-candidate card

## Models actually used

MatterLab uses the upstream CHGNet 0.3.0 checkpoint through the CHGNet 0.4.2 package for local energies, atomic forces, and stresses. It does not train or claim authorship of a new foundation model. Checkpoint hashes and exact package versions are recorded in each campaign's provenance.json and requirements-lock.txt. Upstream code, weights, training data, and their licenses remain separate from the MIT project code.

GPT Astra roles assist scientific planning, implementation, and review in signed-in Codex. Agreement between roles is not physical evidence. No paid model API or subscription-credential proxy is implemented. Saved calculations run without a GPT account or API key once their free dependencies and weights are installed.

## Generation method

Candidate structures are generated by deterministic enumeration of isovalent Ca/Sr/Ba and Ti/Zr/Sn occupations on a four-formula-unit ABO3 parent cell, parent-symmetry deduplication, seeded selection, and initial distortions. This is not a trained crystal-diffusion model and is not an execution of MatterGen. The generated hypotheses include explicit compositions and atomic arrangements; their global novelty and synthesizability are unverified.

## Intended use

- Reproducible early-stage computational materials screening.
- Investigation of the relationship between composition, ordering, model energy, and constrained mechanical response.
- Open data for algorithm and potential evaluation, including failed and inconclusive calculations.
- Subsequent dielectric-ceramic and composite-filler research when application-specific evidence is obtained.

## Unsupported uses and uncertainty

Do not treat outputs as experimentally synthesized materials, manufacturing instructions, certified product specifications, a full phase diagram, or proof of a world's-first invention. CHGNet predictions can be inaccurate outside its training domain; numerical reproducibility does not establish physical accuracy. This project has no calibrated candidate-level uncertainty distribution.

The first campaign uses one small periodic cell and limited initial structures/reference phases. Its energy threshold is triage only. EOS results use fixed-shape cell scaling. Gamma curvatures use finite displacements, retain numerical residuals, and do not cover all phonon wave vectors. Two detailed first-round Gamma diagnoses are inconclusive. Known-reference DFT execution does not validate generated candidates.

## Evidence and candidate cards

Each candidate's result.json is its machine-readable card: identifier, composition, initial seed, structure, method-stage status, observations, diagnostic scope, potential applications, missing tests, and links to raw evidence. The English dashboard renders that card without an external API. Published scientific claims must be traceable to these records and their immutable run snapshots.

Future model or physics-method changes require a new recorded run and an explicit comparison; do not silently replace an old result or label a surrogate-model prediction as DFT.
